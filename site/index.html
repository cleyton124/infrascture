Como a Automação Funciona

Este projeto utiliza o conceito de Infrastructure as Code (IaC). Toda a arquitetura da nuvem foi escrita em arquivos de configuração declarativos e executada de forma automática.

Etapas do Processo

  • GitHub Actions: Atua como o orquestrador, capturando os eventos e disparando os comandos de implantação.
  • Terraform: Lê o estado desejado, conecta-se à API da AWS e cria o Bucket S3 com as políticas de acesso corretas.
  • AWS S3 Website: O bucket é configurado para servir arquivos estáticos (`index.html`), gerando uma URL pública acessível.
